Eenmalige setup

Plak hier je GitHub Personal Access Token. Die heb je nodig om de scraper te starten. Maak een token aan → Repository access: alleen my-web-scraper → Permissions: Actions Read and write + Contents Read. Token blijft op je eigen browser (localStorage), wordt nergens anders bewaard.
